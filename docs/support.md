# Support

For setup problems or a data-deletion request, [open a GitHub issue](https://github.com/Anneo22/ticktick-garmin/issues/new).

Include your Garmin model, app version, the exact message shown on the watch, and whether the failure happened during pairing, refresh, or a task action. Do not send TickTick passwords, access tokens, relay tokens, device secrets, or screenshots that expose private task content.

Known release limits are tracked in the [public repository](https://github.com/Anneo22/ticktick-garmin).
